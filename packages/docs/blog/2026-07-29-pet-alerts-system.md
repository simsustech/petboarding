# Pet Alerts System

Pets can now carry alerts with an optional date range. Four built-in conditions are available out of the box — in heat, needs rest, aggressive, diabetic — each with its own icon and color. Alerts appear as colored badges on the pet card, the kennel-layout chip, the booking item, and the pet legend, so staff can see at a glance which pets need special attention on the day they are handling them.

## What changed

- Pets can have one or more alerts. Each alert has a condition and an optional start and end date.
- Four conditions ship built-in: in heat, needs rest, aggressive, and diabetic. Each has a distinct icon and color so they are easy to recognize in a busy view.
- Alerts are added and managed from a dialog on the pet card. The form lists existing alerts, lets you add a new one, and lets you remove an alert.
- The confirmation dialog for removing an alert shows the condition, the pet's name, and the date range, so it is clear what is being deleted before confirming.
- An alert with no end date is treated as ongoing from its start date forward. An alert with only a start date applies on that single day.
- The kennel layout and the daycare view only show badges for alerts that are active on the date being viewed, so the staff only sees what matters today.

## How this improves things

Staff no longer need to remember special notes about a pet from the booking notes or a side conversation — the alert is right there on the pet in every relevant view. Date ranges mean a temporary condition (a pet in heat, or recovering from a procedure) stops appearing once it is over, without anyone having to clean it up. The color and icon coding makes it possible to scan a crowded kennel layout or a long booking list and spot the pets that need extra care before walking up to them.
