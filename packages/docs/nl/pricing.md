# Prijzen

Petboarding is beschikbaar als een beheerde **Cloud**-abonnement of als **Self-Hosted** open-source editie.

---

De eenvoudigste manier om Petboarding te gebruiken. Wij hosten, onderhouden en beveiligen alles — u logt gewoon in en runt uw bedrijf.

| | |
|---|---|

Geen servers om te beheren. Geen backups om u zorgen over te maken. Geen SSL-certificaten om te vernieuwen. Gewoon een betrouwbaar systeem dat altijd klaar staat.

## Self-Hosted — Gratis (Open-Source)

Petboarding is gebouwd op open-source principes. Als u het liever op uw eigen infrastructuur draait, is de volledige applicatie gratis beschikbaar — geen functiebeperkingen, geen proefperiode.

| | |
|---|---|
| **Prijs** | **€0** — gratis |
| **Licentie** | ELv2 — gebruik, wijzig en host zelf vrijelijk |
| **Infrastructuur** | U zorgt voor uw eigen server en PostgreSQL-database |
| **Alle functies inbegrepen** | Dezelfde functionaliteit als Cloud |
| **Updates** | Haal de nieuwste Docker-images handmatig op |
| **Ondersteuning** | Community-ondersteuning via GitHub |

Zie de [README op GitHub](https://github.com/simsustech/petboarding#quickstart) voor installatie-instructies.
