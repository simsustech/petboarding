# Pricing

Petboarding is available as a managed **Cloud** subscription or as a **Self-Hosted** open-source edition.

---

## Cloud — €40 / month

The easiest way to use Petboarding. We host, maintain, and secure everything — you just log in and run your business.

| | |
|---|---|
| **Price** | **€40** per month |
| **Hosting** | Managed by us — high availability, automatic daily backups, security updates |
| **All features included** | Full customer portal, boarding management, daycare, kennel layout, email notifications, and more |
| **Updates** | Always up-to-date — we apply updates automatically |
| **Support** | Email support with priority response |
| **Data** | Backed up daily |
| **Security** | SSL certificates, database maintenance, and security patches handled for you |
| **Cancellation** | Cancel anytime, no long-term contracts |

No servers to manage. No backups to worry about. No SSL certificates to renew. Just a reliable system that's always ready.

SlimFact integration included — invoicing and payment processing.

[View the Demo](https://demo.petboarding.app)

## Self-Hosted — Free (Open-Source)

Petboarding is built on open-source principles. If you prefer to run it on your own infrastructure, the full application is available for free — no feature limitations, no trial period.

| | |
|---|---|
| **Price** | **€0** — free |
| **License** | ELv2 — use, modify, and self-host freely |
| **Infrastructure** | You provide your own server and PostgreSQL database |
| **All features included** | Same feature set as Cloud |
| **Updates** | Pull the latest Docker images manually |
| **Support** | Community support via GitHub |

See the [README on GitHub](https://github.com/simsustech/petboarding#quickstart) for setup instructions.
