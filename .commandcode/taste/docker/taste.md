# docker
- When using docker compose up, avoid --build (it can use stale cache). Instead, precede with "docker compose -f [file] build --no-cache" and run the up command without --build. Confidence: 0.60
- Before every new test run, always run `docker compose -f docker-compose.test.yaml down --volumes` to ensure a clean database state with no stale seed data. Confidence: 0.85
- For local package development in Docker builds: mount the local source via BuildKit additional_contexts, detect it in the Dockerfile with a conditional check for package.json, build the local package first (`pnpm install && pnpm run build`), then use `pnpm link /path/to/local/folder` (link by folder path, not by package name — `pnpm link /path/to/pkg`, not `pnpm link @scope/pkgname`). Make the overlay mechanism generic — don't hardcode specific package names; it should work for any linked package via the additional_contexts. Fall back to normal frozen-lockfile install when no local package is mounted. Keep it in one Dockerfile — no separate dev Dockerfiles. Confidence: 0.85
- For multiple local packages in Docker builds, use separate named additional_contexts per package (e.g., `linked-quasar-components`, `linked-vitrify`) rather than a single context pointing to a directory of symlinked packages. Each context is referenced individually in the Dockerfile via `COPY --from=linked-quasar-components`. Do not require a host-level aggregation directory. Confidence: 0.80
- For local package Docker contexts, use the `linked-` prefix naming convention (e.g., `linked-quasar-components`, `linked-vitrify`) to distinguish linked-package contexts from other context types. Confidence: 0.70
- In the Dockerfile, use `/build/local-packages/` as the base path for local package overlays — not `/build/local-packages/linked/`. The "linked" qualifier is redundant since local packages in Docker are always linked. Confidence: 0.70
- The test staging workflow (docker-compose.test.yaml) must always build from source via `docker compose up --build` — never use a pre-built image. It exists to test local changes and needs the additional_contexts for linked package overlays. Confidence: 0.65
